# Laboratory work 3

Utilities for working with files and directories in Linux:
- `dir.py` — directory listing utility similar to `ls`
- `clean.py` — utility for finding and deleting empty files and directories

## Run

```bash
python3 dir.py
python3 dir.py -a
python3 dir.py -l
python3 dir.py -a -l

python3 clean.py
python3 clean.py --files
python3 clean.py --dirs
python3 clean.py --delete-files
python3 clean.py --delete-dirs
```
